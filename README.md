# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 今晚桌单

聚会排桌用的当晚清单（数据保存在本地 localStorage）：

1. 先填今晚到场人数，可选列表只出现**人数合适且还没排过**的收藏，按久未玩优先排序。
2. 加入后可用 ↑/↓ 调整顺序，随时「挪走」任意一盒。
3. 再放一盒会让总时长超过 3 小时（180 分钟）时提示放不下，该盒不会加入；换人（改人数）或挪走一盒后自动重新计算。
4. 到场人数改变后，已排入但不合适的桌游会标红，并标注不计入时长。
5. 「确认桌单」后按今晚顺序列出每盒容易忘的规则和常见争议，方便开局前快速过一遍。
6. 「今晚结束」时记录实际参与人数，自动写入历史场次、把玩过的桌游更新为今天，然后清空桌单。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
